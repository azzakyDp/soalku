# Workflow backend yang dibundel

Folder skill di sini disalin dari paket Superpowers 6.4.2 yang sudah terpasang
pada mesin pengembangan. Sumber upstream: paket plugin Superpowers; copyright
2025 Jesse Vincent, lisensi MIT. Teks lisensi disertakan pada
[SUPERPOWERS-LICENSE](SUPERPOWERS-LICENSE).

Salinan mencakup `using-superpowers`, `brainstorming`, `test-driven-development`,
`systematic-debugging`, `verification-before-completion`, `receiving-code-review`,
`requesting-code-review`, `writing-plans`, dan `executing-plans`, beserta berkas
referensinya. Baca `SKILL.md` skill yang sesuai sebelum menggunakannya.

Instruksi manusia dan aturan project pada [AGENTS.md](../../AGENTS.md) memiliki
prioritas. Ketersediaan skill tidak mengizinkan implementasi step berikutnya,
memanggil layanan berbayar, membuat commit di luar cakupan, atau mengirim pesan
ke layanan eksternal tanpa otorisasi. File-file ini tidak berisi API key atau
konfigurasi akun pengembang.
